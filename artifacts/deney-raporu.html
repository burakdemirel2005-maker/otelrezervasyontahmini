Sınırlar ve duyarlılık

İki Portekiz oteli, 2015–2017. Snapshot değişkenlerinin her birinin zaman damgası doğrulanamaz. Tekrarlanan satırlar gerçek grup rezervasyonları olabilir; ana deneyde korunur. Tekilleştirilmiş testte AP 0.4715, AUC 0.697. Gün bloklarıyla 200 bootstrap AP %95 aralığı [0.6463, 0.7142]. Bu aralık yeni otelde genelleme belirsizliğini kapsamaz.

Tekrar üretme

Python 3.12 ortamında requirements.txt bağımlılıklarını kurun. python train.py modeli ve ölçümleri, python rapor.py bu raporu üretir. python -m pytest -q kontrolleri çalıştırır. Test sonrası yeni model seçilmemiştir.
